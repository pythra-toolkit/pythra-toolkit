# Security Policy

## Supported Versions

As this project is currently in active beta development (`v0.1.x`), we prioritize security updates for the most recent release. Users are strongly encouraged to upgrade to the latest version to ensure they have the latest security patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of **PyThra** seriously. If you believe you have found a security vulnerability, please report it to us as described below.

### Where to Report

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please use one of the following methods:

1.  **GitHub Private Reporting (Preferred):**
    *   Go to the [Security tab](https://github.com/pythra-toolkit/pythra-toolkit/security) on our repository.
    *   Click on **Advisories**.
    *   Click the **"Report a vulnerability"** button.
    *   This allows you to open a private advisory where we can discuss the issue securely.

2.  **Email:**
    *   If you cannot use GitHub Private Reporting, you may email the maintainers directly at: **[ambashir02@gmail.com]**

### What to Include

To help us triage and fix the issue efficiently, please include:

*   A description of the vulnerability.
*   Steps to reproduce the issue (including code snippets or a proof-of-concept).
*   The version of **PyThra** you are using.
*   Any relevant platform or environment details (e.g., OS, Python version).

### Our Response Policy

*   We aim to acknowledge receipt of your report within **48 hours**.
*   We will investigate the issue and determine its impact.
*   If the vulnerability is accepted, we will work on a fix and release a security patch as soon as possible.
*   We will notify you once the fix is released.
*   We will not publicly disclose the vulnerability until a fix is available and users have had a reasonable amount of time to upgrade.

Thank you for helping keep PyThra secure!
